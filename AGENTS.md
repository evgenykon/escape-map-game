# Правила проекта

## Всё — через Docker

Запуск frontend напрямую (вне Docker-контейнера) **запрещён**.

### Почему
- Окружение должно быть изолированным и воспроизводимым

### Как запускать

```bash
# Frontend dev (hot-reload):
make dev

# Production сборка:
make build
make run
```

### Что запрещено

- `npm run dev` — только через Docker
- любые прямые запуски процессов без Docker

### Makefile

```bash
make dev       # Запуск dev-сервера с hot-reload (Docker)
make build     # Production сборка
make run       # Запуск production сборки (nginx)
```

### Структура Docker-сервисов

```
  frontend-dev (Node + Vite hot-reload, через volumes)
  frontend (nginx, production)
```

**Локальный дев (dev профиль):**
1. `frontend-dev` с Vite hot-reload на порту 3001
2. Статические данные, WebSocket не используется

**Production профиль:**
1. `frontend` — nginx со статикой

### Сервисы

| Сервис | Образ | Порт |
|---|---|---|
| `frontend-dev` | `node:24-alpine` | 3001 |
| `frontend` | nginx:alpine | 80 |

## Архитектура игры

### Стек

| Компонент | Технология |
|---|---|
| Язык / Сборка | TypeScript + Vite |
| Карта | MapLibre GL JS |
| UI (меню, HUD, смски) | Vue 3 + Composition API |
| Состояние игры | Pinia |
| OSM данные | Overpass API (запрос при старте) |
| Гео-анализ | Turf.js |
| Физика машины | Кастомная (ускорение, торможение, заносы) |

### Геймплей

- **Старт**: игрок подтверждает текущую геопозицию
- **Эпицентр**: 1 км от игрока в случайном направлении
- **Загрузка**: Overpass API — дороги и здания в радиусе ~15 км, строится граф дорог (для снэпа машины на дорогу), выбираются 15–20 убежищ (здания на дистанции 5–10 км от эпицентра)
- **Управление**: WASD (движение), вращение камеры за персонажем, E — сесть/выйти из машины
- **Машина**: движение только по дорогам (снэп к ближайшему сегменту графа)
- **Пешком**: движение везде
- **Таймер**: 5–10 минут (рандом), настраивается на стартовом экране
- **Оповещения**: SMS-сообщения об оставшемся времени (имитация правительственных уведомлений)
- **Взрыв**: расходящиеся круги от эпицентра. Если игрок не внутри убежища — game over
- **Убежища**: рандомные здания на кольце 5–10 км от эпицентра, подсвечены на карте

### Поток экранов

```
[Стартовый экран]
  ├─ Выбор сложности (таймер, мощность взрыва)
  └─ Кнопка "Старт" → определение геопозиции

[Загрузка]
  ├─ Overpass API: дороги + здания
  ├─ Сборка графа дорог
  ├─ Выбор убежищ
  └─ Переход в игру

[Игра]
  ├─ MapLibre (подложка, кастомные слои)
  ├─ WASD + E (движение, машины)
  ├─ HUD (таймер, SMS-оповещения)
  └─ Взрыв → победа/поражение
```

### Деплой

```bash
make dev
make build
make run
```

## Все команды — только через Makefile

Запуск `bun`, `npm`, `vite` или любых других команд напрямую **запрещён**. Все действия — только через цели в `Makefile`.
